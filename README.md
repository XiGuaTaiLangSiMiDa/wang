# 布林带交易策略回测系统

基于布林带的加权多空策略回测系统，支持多时间周期组合分析。

## 策略说明

### 入场条件（仅做多）
- 15分钟布林带：
  - 中轨支撑权重：1
  - 下轨支撑权重：2
- 1小时布林带：
  - 中轨支撑权重：2
  - 下轨支撑权重：4
- 4小时布林带：
  - 中轨支撑权重：3
  - 下轨支撑权重：6

### 出场条件
- 止损：亏损达到本金的50%（50u）
- 止盈：收益达到本金的50%～100%（50～100u）
- 阻力位退出（使用非入场时间周期的布林带）：
  - 15分钟布林带：上轨-2，中轨-1
  - 1小时布林带：上轨-4，中轨-2
  - 4小时布林带：上轨-6，中轨-3

### 交易规则
- 初始资金：100 USDT
- 杠杆倍数：100x
- 单次持仓：同时只能开一单
- 持仓管理：结束当前单前不追加/不新开单

## 安装

1. 克隆项目
```bash
git clone <repository_url>
cd <project_directory>
```

2. 安装依赖
```bash
yarn install
```

3. 配置环境变量
复制 `.env.example` 到 `.env` 并填入 OKX API 凭证：
```
API_KEY=your_api_key
API_SECRET=your_api_secret
PASSPHRASE=your_passphrase
```

## 使用方法

1. 运行回测
```bash
# 默认分析最近180天数据
node src/main.js

# 指定分析天数（例如分析最近90天）
node src/main.js 90

# 其他常用分析周期
node src/main.js 60  # 分析最近60天
node src/main.js 30  # 分析最近30天
node src/main.js 7   # 分析最近7天
```

注意：
- 系统会缓存6个月的历史数据，避免重复下载
- 可以随时指定不同的分析周期，而无需重新下载数据
- 分析结果会显示具体的日期范围

2. 查看可视化结果
- 直接在浏览器中打开 `src/visualization/index.html`
- 回测结果会自动更新到可视化界面

## 可视化界面

可视化界面包含以下内容：
- K线图展示
  - 支持15分钟/1小时/4小时时间周期切换
  - 显示布林带指标
  - 标记交易入场和出场点位
  - 交易详情悬浮提示
- 整体表现指标
- 交易退出分析
- 收益指标统计
- 图表分析
  - 交易退出类型分布
  - 各类型平均收益
  - 累计收益曲线
- 时间周期组合分析
- 详细交易记录

## 数据管理

### 数据下载和缓存
- 系统会下载并缓存最近6个月的历史数据
- 缓存的数据保存在 `data` 目录下
- 后续运行时会自动增量更新数据
- 缓存机制避免重复下载，提高分析效率

### 数据分析
- 可以指定任意天数进行分析（如7天、30天、90天等）
- 分析使用缓存的数据，无需重新下载
- 每次分析会生成带时间戳的结果文件
- 结果包含分析周期的起止时间

### 结果存储
- 回测结果保存在 `results` 目录
- 文件名包含分析天数和时间戳
- 最新结果自动同步到可视化界面
- 可以比较不同时期的分析结果

## 注意事项

1. 首次运行会下载半年的历史数据，可能需要一些时间
2. 确保 API 密钥有足够的权限获取历史数据
3. 可以随时切换分析周期，系统会复用已缓存的数据
4. 分析结果包含完整的交易记录和详细统计
5. 可视化界面会自动显示最新的分析结果
