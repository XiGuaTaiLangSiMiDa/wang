# 合约交易预测系统

## 操作说明

### 1. 训练界面操作步骤

1. 打开训练界面 http://localhost:3000/visualization/contract_training.html

2. 加载数据：
   - 选择时间范围（例如：最近7天）
   - 选择K线周期（15分钟、1小时、4小时）
   - 选择需要显示的技术指标
   - 点击"加载数据"按钮

3. 标记K线：
   - 在K线图上点击任意K线，会出现一个蓝色的垂直选择线
   - 在右侧会弹出操作按钮：
     * 点击"开多/平空"按钮：标记为做多信号（绿色上箭头）
     * 点击"开空/平多"按钮：标记为做空信号（红色下箭头）
     * 点击"取消"按钮：取消当前选择

4. 查看标记：
   - 右侧面板会显示所有标记的历史记录
   - 标记记录包含时间、操作类型和价格信息
   - 绿色边框表示做多标记
   - 红色边框表示做空标记

5. 训练模型：
   - 完成足够的标记后（建议至少100个标记点）
   - 点击"训练模型"按钮开始训练
   - 训练过程会显示进度和准确率
   - 训练完成后会自动保存模型

### 2. 标记建议

1. 做多信号标记时机：
   - 明显的底部反转形态
   - 突破重要阻力位
   - 强势上涨趋势中的回调企稳
   - MACD金叉且RSI回升
   - 成交量放大配合价格上涨

2. 做空信号标记时机：
   - 明显的顶部反转形态
   - 跌破重要支撑位
   - 下跌趋势中的反弹结束
   - MACD死叉且RSI回落
   - 成交量放大配合价格下跌

3. 注意事项：
   - 尽量在趋势明确的位置标记
   - 关注多个技术指标的配合
   - 避免在盘整区间频繁标记
   - 结合成交量变化进行判断
   - 注意市场整体氛围

### 3. 技术指标说明

1. 移动平均线（MA）：
   - MA5：短期趋势
   - MA10：中期趋势
   - MA20：长期趋势
   - 多头排列：短期均线在上，长期均线在下
   - 空头排列：短期均线在下，长期均线在上

2. 布林带（Bollinger Bands）：
   - 上轨：压力位
   - 中轨：均价线
   - 下轨：支撑位
   - 带宽：反映波动性

3. MACD指标：
   - MACD线：反映趋势方向
   - Signal线：信号线
   - 柱状图：趋势强度
   - 金叉：看多信号
   - 死叉：看空信号

4. RSI指标：
   - 70以上：超买区
   - 30以下：超卖区
   - 50中轴：趋势分界

### 4. 模型训练效果

1. 统计信息：
   - 总标记数：已标记的K线数量
   - 做多数量：做多标记的数量
   - 做空数量：做空标记的数量
   - 数据覆盖率：标记点占总K线的比例

2. 训练进度：
   - 训练轮次（Epoch）
   - 训练损失（Loss）
   - 训练准确率（Accuracy）
   - 验证损失（Validation Loss）
   - 验证准确率（Validation Accuracy）

### 5. 使用建议

1. 标记步骤：
   - 先观察整体走势和趋势
   - 找到明确的转折点
   - 确认多个技术指标共振
   - 点击相应K线进行标记
   - 记录标记原因（可选）

2. 训练要点：
   - 保持标记的一致性
   - 避免过度标记相似位置
   - 确保做多做空标记相对均衡
   - 定期重新训练更新模型
   - 验证模型预测效果

3. 注意事项：
   - 标记时注意时间连续性
   - 避免在高波动期频繁标记
   - 关注重要价格关卡
   - 结合基本面信息
   - 保持耐心和客观性
