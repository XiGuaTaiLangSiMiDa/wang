# 布林带交易策略回测系统

基于布林带的加权多空策略回测系统，支持多时间周期组合分析。

## 策略说明

### 入场条件（仅做多）
- 15分钟布林带：
  - 中轨支撑权重：1
  - 下轨支撑权重：2
- 1小时布林带：
  - 中轨支撑权重：2
  - 下轨支撑权重：4
- 4小时布林带：
  - 中轨支撑权重：3
  - 下轨支撑权重：6

### 出场条件
- 止损：亏损达到本金的50%（50u）
- 止盈：收益达到本金的50%～100%（50～100u）
- 阻力位退出（使用非入场时间周期的布林带）：
  - 15分钟布林带：上轨-2，中轨-1
  - 1小时布林带：上轨-4，中轨-2
  - 4小时布林带：上轨-6，中轨-3

### 交易规则
- 初始资金：100 USDT
- 杠杆倍数：100x
- 单次持仓：同时只能开一单
- 持仓管理：结束当前单前不追加/不新开单

## 安装

1. 克隆项目
```bash
git clone <repository_url>
cd <project_directory>
```

2. 安装依赖
```bash
yarn install
```

3. 配置环境变量
复制 `.env.example` 到 `.env` 并填入 OKX API 凭证：
```
API_KEY=your_api_key
API_SECRET=your_api_secret
PASSPHRASE=your_passphrase
```

## 使用方法

1. 运行回测
```bash
node src/main.js
```

2. 查看可视化结果
- 直接在浏览器中打开 `src/visualization/index.html`
- 回测结果会自动更新到可视化界面

## 可视化界面

可视化界面包含以下内容：
- K线图展示
  - 支持15分钟/1小时/4小时时间周期切换
  - 显示布林带指标
  - 标记交易入场和出场点位
  - 交易详情悬浮提示
- 整体表现指标
- 交易退出分析
- 收益指标统计
- 图表分析
  - 交易退出类型分布
  - 各类型平均收益
  - 累计收益曲线
- 时间周期组合分析
- 详细交易记录

## 目录结构

```
├── src/
│   ├── calculator.js     # 布林带计算模块
│   ├── fetcher.js       # 数据获取模块
│   ├── strategy.js      # 策略实现模块
│   ├── main.js          # 主程序
│   └── visualization/   # 可视化相关文件
│       ├── index.html   # 可视化界面
│       └── latest_results.json  # 最新回测结果
├── data/                # 缓存的历史数据
├── results/            # 回测结果历史记录
├── .env                # 环境变量配置
└── README.md           # 项目说明文档
```

## 数据存储

- 历史数据缓存在 `data` 目录
- 回测结果保存在 `results` 目录
  - 每次回测会生成带时间戳的结果文件
  - 最新结果自动同步到可视化界面

## 注意事项

1. 首次运行会下载半年的历史数据，可能需要一些时间
2. 确保 API 密钥有足够的权限获取历史数据
3. 历史数据会缓存在本地，后续运行会增量更新
4. 可视化界面会自动显示最新的回测结果
5. 回测结果包含完整的交易记录和分析数据
